# Kernel Clash

A creature-battler that teaches operating systems, from system calls to interview level. Sibling of [Query Clash](https://github.com/anmol-pawa/query-clash).

Play: https://anmol-pawa.github.io/kernel-clash/ (installable, works offline).

```sh
npm ci
npm run dev          # http://localhost:3000
npm test             # sprite + simulator tests
npm run build:pages  # static PWA in out/ (BASE_PATH=/kernel-clash)
npm run icons        # regenerate the pixel app icons
```
